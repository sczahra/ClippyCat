# v1.7 Stretch and Scratch Plan

## Base commit

`27a99faf1d23912be1799c8c956c01078f777943`

## Current PetAction architecture

- `PetAction` represents the existing actions that can be selected without exposing sprite-row details.
- `SelectNextAutonomousAction` preserves the energy-dependent random weights and returns a `PetAction`.
- `PerformPetAction` is the single dispatcher from a selected action to the existing state-entry methods.
- The tray menu's **Do Something** command chooses an action and uses the same dispatcher.
- `PetState` names are observed automatically by the existing reflection-based diagnostics, so distinct state values are sufficient for diagnostic names.

## Stretch implementation plan

- Add `PetAction.Stretch` and `PetState.Stretch`.
- Add one `EnterStretch` state-entry method and dispatcher case.
- Reuse the existing pawing artwork: row 7, 6 frames.
- Use a slower frame delay of about 280 ms so the first pose provides a short setup and the sequence feels more deliberate than ordinary pawing.
- Use a randomized duration of 1.8-2.7 seconds, with no horizontal movement, then allow the existing state-completion path to return naturally to normal behavior.
- Treat it as a light action for energy accounting, matching the existing one-point action cost group.

## Scratch implementation plan

- Add `PetAction.Scratch` and `PetState.Scratch`.
- Add one `EnterScratch` state-entry method and dispatcher case.
- Reuse the existing grooming artwork: row 5, 8 frames.
- Use a quicker frame delay of about 150 ms so the grooming motion reads as a brief itch response rather than the existing slower grooming state.
- Use a randomized duration of 1.6-2.4 seconds, with no horizontal movement, then allow normal state completion.
- Treat it as a light action for energy accounting, matching the existing one-point action cost group.

## Selection integration

- Expand **Do Something** from five equally likely supported actions to seven, making Stretch and Scratch directly reachable without adding UI commands.
- At normal energy, assign Stretch 3% and Scratch 3%, taken only from Idle's existing 34% share; all other existing action weights remain unchanged.
- At high energy, assign Stretch 3% and Scratch 3%, taken only from Idle's existing 12% share; all other existing action weights remain unchanged.
- Do not add either action to the tired/low-energy selection branch.
- Use identical logic for Marmalade and Merry.

## Reused artwork and limitations

- Stretch approximation: pawing row 7, 6 frames.
- Scratch approximation: grooming row 5, 8 frames.
- Neither sequence is dedicated Stretch/Scratch artwork. Timing and distinct state names make the actions readable enough for this dispatcher-extension milestone, but the poses will remain recognizable as reused pawing/grooming animations.
- No sprite sheet will be edited, regenerated, resized, or replaced.
