## Generation and recovery notes

- The first Merry Scratch generation had visually usable cat poses but an RGB checkerboard that contaminated portions of the white coats/tails. A targeted background-extraction edit returned a worse opaque checker and was rejected.
- Rather than destructively keying white/gray fur, the action was regenerated with the same references and pose constraints on a flat saturated magenta extraction background.
- Merry Scratch, Marmalade Yawn, and Merry Yawn were delivered from RGB chroma sheets. Only connected saturated-magenta background regions were removed; no white, gray, or orange color key was used.
- After uniform premultiplied-alpha downscaling, 0-8 isolated magenta resampling pixels per frame were cleared. The final 24 source frames contain zero detected high-saturation magenta pixels.
- All actions use a shared per-action scale and a common y=203 baseline. No source frame contains preview checkerboard pixels or review labels.

## Quality-gate result

All three requested actions pass the technical and visual source-frame gates and are approved for manifest/importer integration. Human runtime review is still required later for perceived timing and animation flow.
