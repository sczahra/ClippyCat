### Marmalade

- The existing Scratch tray item uses `TriggerAction(PetAction.Scratch)`.
- The shared manifest dispatcher resolves Scratch to `PetState.Scratch`, row 12, 8 frames, and the manifest timing.
- Do Something includes Scratch because it is random-eligible and available for the active Marmalade pet.
- Autonomous selection includes Scratch at conservative weight 2 and takes that weight only from the existing Idle bucket.
- Scratch has no horizontal movement and uses the same light energy cost category as Stretch.

- Merry Scratch remains disabled in the manifest.

- Merry Stretch remains disabled/pending exactly as before.
