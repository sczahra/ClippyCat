# ClippyCat v2.6.1 updater proof plan

- Starting SHA: `a32785d2b9e62398e91ce768fd2cd14406636f3b`
- Working tree: clean; local `HEAD` and `origin/main` match after fetching `origin`.

## Current version sources

- `MarmaladeDesktopPet.csproj` contains the authoritative application/package version (`2.6.0`). The generated assembly and product metadata inherit this value.
- `Program.cs` reads the running assembly version through `UpdateService.CurrentVersion`, but the About text currently displays only major and minor components.
- `Build-Installer.ps1` reads the project version and derives the installer and checksum filenames from it.
- `installer/ClippyCat.iss` accepts the project-derived version from `Build-Installer.ps1` and contains `2.6.0` only as its direct-build fallback.
- `README.md` documents the current concrete installer filename.

## Exact visible change

- Show `ClippyCat` and `Version 2.6.1` in About using the existing three-part version formatter.
- Add the single concise About line `Updater validation release`.

## Packaging/version updates

- Set the authoritative project version to `2.6.1`.
- Update the Inno Setup fallback version to `2.6.1` so direct and scripted installer builds agree.
- Update only the README examples that name the concrete current installer.
- No new version constant or packaging mechanism will be introduced.

## Updater release contract

- Expected stable tag: `v2.6.1`.
- Expected installer asset: `ClippyCatSetup-2.6.1.exe`.
- Expected checksum asset: `ClippyCatSetup-2.6.1.exe.sha256`.
- The existing updater accepts a non-draft, non-prerelease three-part tag newer than the installed assembly version and requires exactly those matching asset names.

## Out of scope

- Pet behavior, animations, artwork, action manifest, settings format, tray behavior, startup behavior, and updater architecture.
- GitHub Release creation or publication.
