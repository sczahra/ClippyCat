## Artwork approach

- Inspect the production atlases once and extract only useful reference cells into `codex-checkpoints/v2.4-analysis/`.
- Ear Twitch, Sleepy Blink, and Head Shake start from one exact production seated frame per pet. Neutral/recovery frames reuse it directly; generated edits will be accepted only for the smallest changed head/ear/eye region and composited over unchanged production pixels where practical.
- Look Behind will reuse production waiting/review/mouse-look head-turn geometry and a stable production body.
- Loaf will use accepted Sit/Settle and Roll/Flop resting frames as pose/style references.
- Knead will use Pawing, Sit/Settle, Scratch, and resting source frames as pose/style references, with the torso kept stable and only attached front-paw motion changing.
- Built-in reference-image generation is used only where direct reuse cannot express the requested pose. Generated flat backgrounds will be removed conservatively; good art will not be discarded merely for recoverable RGB background output.
- After each action, validate exact frame count, 192x208 RGBA format, alpha, clean background, baseline, anatomy, identity, and preview quality before proceeding.

## Manifest/import plan

- Add only actions whose two pet packs pass validation, following v2.3 `id`, `displayName`, `enabled`, `menuOrder`, timing, eligibility, row, and per-pet conventions.
- Run the existing `Import-Actions.ps1` twice.
- Verify old rows pixel-identical, new atlas cells source-identical, unused cells transparent, second import idempotent, and no unnecessary backups.
- Build with `dotnet build`, run `git diff --check`, and require `git diff -- Program.cs` to be empty.

## Explicit scope boundary

`Program.cs` is out of scope and will not be modified, including for an About version bump. If the content cannot work through assets plus `actions.json` and the existing scripts, the affected action will be stopped and documented rather than bypassing v2.3.

Also out of scope: packages, runtime/importer refactoring, settings, diagnostics, new mechanics, Merry Stretch, replacement of existing artwork, or changes to existing animation rows/timing/weights.
