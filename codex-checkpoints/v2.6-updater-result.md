## Updater architecture

- `MarmaladeDesktopPet.csproj` is the application version source of truth through `<Version>2.6.0</Version>`. SDK-generated product/file/assembly metadata supplies the installed version.
- About displays `Version 2.6` from assembly metadata. Diagnostics and the updater report `2.6.0` from the same metadata.
- `UpdateService` owns stable GitHub API access, release parsing, exact asset selection, download limits, temporary-file handling, SHA-256 verification, and normal shell launch of a verified installer.
- `UpdateDialog` is a native WinForms dialog that shows installed/available versions, capped plain-text release notes, Download and Install/Later actions, cancellable responsive download progress, verification status, and friendly failures.
- No external packages, Git, PowerShell, repository files, browser control, background service, self-modification, silent installation, UAC bypass, prerelease channel, or test endpoint is present in the installed application.

## Release contract and version parsing

- Accepted stable tags: `vX.Y.Z` and `X.Y.Z` with exactly three numeric components.
- Versions are parsed with `System.Version` and compared semantically; same, older, draft, prerelease, and malformed releases are not offered.
- Required assets for a release version are exactly:
  - `ClippyCatSetup-X.Y.Z.exe`
  - `ClippyCatSetup-X.Y.Z.exe.sha256`
- Missing, duplicate, incorrectly named, non-HTTPS, or non-GitHub download assets fail safely.
- Release HTML is stripped, basic Markdown is simplified to plain text, and the displayed summary is capped at 1,200 characters.

## Integrity and launch behavior

- The checksum is downloaded first, limited to 64 KiB, and must contain one valid 64-hex SHA-256 with an optional matching installer filename.
- The installer is limited to 512 MiB and downloaded to an `.download` file under `%LOCALAPPDATA%\MarmaladeDesktopPet\Updates\X.Y.Z`.
- The installer hash is computed with `System.Security.Cryptography.SHA256` and compared case-insensitively.
- A mismatch deletes incomplete files, logs the failure, never launches the installer, and leaves ClippyCat running.
- Verified files are promoted to their final names. SHA-256 is recomputed immediately before shell launch.
- ClippyCat exits only after `Process.Start` successfully opens the verified installer; launch failure keeps the current app running.
- Existing settings remain in `%LOCALAPPDATA%\MarmaladeDesktopPet\settings.json` and are not touched. Start with Windows continues using `Application.ExecutablePath`, so installed/reinstalled paths remain correct.
