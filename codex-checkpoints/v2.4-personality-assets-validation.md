# ClippyCat v2.4 Personality Pack — Asset Validation

## Scope

- Pets: Marmalade and Merry
- Actions: Ear Twitch, Sleepy Blink, Look Behind, Loaf, Knead, Head Shake
- Total new source frames: 68 (34 per pet)
- Required source format: 192x208 RGBA PNG with real transparency

## Ear Twitch

- Production reference: row 14, frame 0 for each pet.
- Pixel reuse: the complete seated production frame is copied for every frame.
- Changed region: only the viewer-left ear and immediately adjacent root fur (`x=16..74`, `y=0..69`).
- Method: localized 5°, 10°, and 3° rotations of selected production ear pixels; no facial or body repaint.
- Image generation: one Marmalade reference-image attempt was made and rejected for style/anatomy drift. None of its pixels were used.
- Identity/style review: pass; coat, face, eyes, body, paws, tail, scale, and baseline remain the production reference.
- Technical validation: 8/8 frames pass.

## Sleepy Blink

- Production reference: row 7, frame 0 for each pet.
- Pixel reuse: one fixed production frame per pet is used throughout.
- Changed region: eyelids only (`x=40..111`, `y=43..79` inclusive envelope).
- Method: progressively compressed eye pixels over a feathered reconstruction from immediately adjacent production fur; the closed crease is a two-pixel neutralized compression of the same eye pixels.
- Image generation: not used.
- Identity/style review: pass; no head, muzzle, ear, body, paw, tail, scale, or baseline movement. Merry's green anatomical-left and blue anatomical-right eye colors remain visible in open and partial frames.
- Technical validation: 8/8 frames pass.

## Look Behind

- Production references: row 9 mouse-look frames 0, 2, 4, 7, 4, 0 for each pet.
- Pixel reuse: every frame is a direct production-cell copy; no generated or repainted pixels.
- Changed region: none beyond the differences already present in the accepted production mouse-look sequence.
- Image generation: not used.
- Identity/style review: pass; seated pose, anatomy, scale, baseline, markings, and Merry eye identity remain production art.
- Technical validation: 12/12 frames pass and hash-match their source cells after invisible matte-noise normalization.

## Loaf

- Production references: row 14 Sit/Settle frames 0 through 5 for each pet.
- Pixel reuse: every frame is a direct production-cell copy; no generated or repainted pixels.
- Changed region: none.
- Image generation: not used.
- Identity/style review: pass; progression moves from seated setup through lowered chest to a clear tucked-paw loaf.
- Technical validation: 12/12 frames pass and hash-match their source cells after invisible matte-noise normalization.

## Knead

- Production reference: row 7, frame 0 for each pet.
- Pixel reuse: the fixed seated production frame remains the source for all frames.
- Changed region: lower attached forelegs/paws only (`x=45..141`, `y=140..207` inclusive envelope).
- Method: conservative, feathered left/right paw shears of 2–4 pixels to create an alternating press/return cycle. Torso and head remain fixed.
- Image generation: not used.
- Rejected attempts: two local-transform drafts were rejected because crop-edge sampling produced visible foreleg seams; neither rejected draft remains in the final source pack.
- Identity/style review: pass; no extra limbs, detachment, body drift, identity change, or baseline jump. Motion is intentionally restrained.
- Technical validation: 16/16 frames pass.

## Head Shake

- Production references: row 9 frame 0 fixed body, row 10 frame 3 left head pose, and row 9 frame 5 right head pose for each pet.
- Pixel reuse: only production pixels are used.
- Changed region: head and upper neck; all pixels below `y=124` remain the fixed row 9 frame 0 body.
- Method: feathered upper-neck composite in the sequence neutral, left, center, right, center, neutral.
- Image generation: not used.
- Identity/style review: pass; neck remains attached, body is fixed, no duplicate/blurred face appears, and Merry eye colors remain anatomically correct.
- Technical validation: 12/12 frames pass.

## Cross-pack validation

- 68/68 expected files present.
- 68/68 are exactly 192x208.
- 68/68 are RGBA.
- 68/68 contain transparent pixels and non-empty visible content.
- No opaque rectangular background, checkerboard, text, labels, borders, or visible magenta remains.
- No anatomy is clipped by a cell edge.
- Marmalade and Merry remain at their production scale and baseline.
- Legacy Merry production cells contained isolated `#FF00FF` pixels at alpha 1/255. New source copies normalize only those invisible matte-residue pixels to fully transparent; visible production pixels are unchanged.
