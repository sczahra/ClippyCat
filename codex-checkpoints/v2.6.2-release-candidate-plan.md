# ClippyCat v2.6.2 release candidate plan

- Starting SHA: `be2476587c1929f0664a55fed0a969f97522a7c7`
- Working tree: clean; local `HEAD` and freshly fetched `origin/main` match the expected starting SHA.

## Current version sources

- `MarmaladeDesktopPet.csproj` is the authoritative application/package version source (`2.6.1`); executable assembly, file, and product metadata derive from it.
- `Program.cs` displays the running assembly's three-part version through `UpdateService.CurrentVersionText` and currently includes v2.6.1-only updater-validation wording.
- `Build-Installer.ps1` reads the project version and derives the installer and checksum names without its own version constant.
- `installer/ClippyCat.iss` receives that project-derived version and has `2.6.1` only as its direct-build fallback.
- `README.md` contains concrete current installer and checksum examples.

## Updater GUI polish status

- The update dialog shows marquee download progress until a content length is known, then displays real byte-based percentages.
- It explicitly shows `Verifying update...` during in-process SHA-256 hashing and `Starting installer...` before handoff.
- Both buttons are disabled during download, verification, and launch; errors reset the dialog and leave ClippyCat running.
- Networking and hashing are in-process. Runtime contains no PowerShell, CMD, console helper, or script-based update path.
- The sole external process is the verified Inno Setup executable, launched directly with `ProcessStartInfo` and `UseShellExecute = true`.

## Intended release scope

- Bump the authoritative project version and Inno Setup fallback from `2.6.1` to `2.6.2`.
- Remove the v2.6.1-only `Updater validation release` About line; retain the normal product description and automatic three-part version display.
- Update only the README's concrete current installer/checksum examples.
- Do not change updater logic, packaging architecture, runtime behavior, assets, or dependencies.

## Expected release assets

- Stable tag: `v2.6.2` with `draft=false` and `prerelease=false`.
